# PIXEL-8: 8-Bit CPU Emulator

## Overview
PIXEL-8 is an educational 8-bit CPU emulator developed in C++. It simulates CPU instruction execution, registers, memory and arithmetic operations.

## Features
- Fetch-decode-execute cycle
- 8-bit registers and ALU operations
- Instruction parser, assembler and disassembler
- Register, memory and CPU state management
- Flags, stack and program counter
- Testing and validation

## Technology Stack
- C++
- Standard Template Library (STL)
- VS Code
- Git and GitHub
